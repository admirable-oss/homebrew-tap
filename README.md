# admirable-oss/tap

Homebrew tap for [Hive](https://github.com/admirable-oss/hive): coding agents that keep working when you close the terminal.

```sh
brew install --cask admirable-oss/tap/hive
```

macOS and Linux, on arm64 and amd64. `brew upgrade --cask hive` updates it; `hive update` defers to Homebrew for a hive it installed.

The cask in `Casks/` is generated by Hive's release workflow (GoReleaser) for every stable release. Do not edit it by hand. Release candidates are not published here: install them with `HIVE_CHANNEL=preview` and the [install script](https://github.com/admirable-oss/hive#quick-start).
